Flash Custom Apparel & Signs Live

Marketing site, AI chat, quote intake, and the operations dashboard behind them — for a Houston print shop.

A customer lands on the site, asks the bilingual AI assistant about pricing or turnaround, and requests a quote. The owner gets an email and a text, sees the inquiry on a pipeline board, and can step into the chat mid-conversation when a human answer is better than an AI one.

  • FlashChat — Claude-powered assistant that answers product and pricing questions in English or Spanish, captures quote requests, and hands off to a human with the full transcript.
  • Operations dashboard — order pipeline (New Inquiry → Quoted → Paid → Vendor → QC → Shipped), win/loss reporting, overdue alerts, vendor management, and live visitor presence.
  • Notifications — email with attachments via Resend, SMS via Twilio, all triggered from serverless functions.
  • Data — a 12-table SQLite schema on Cloudflare D1 holding orders, vendors, chat sessions and messages, and quick replies.

HelloBob — AI Virtual Front Desk Open Source

Missed-call text-back and appointment booking for home-service businesses (HVAC first).

When a call goes unanswered, HelloBob texts the caller back within seconds, runs the conversation over SMS, qualifies the job, and books it against the business's real availability. The owner sees every lead, booking, and review request on a dashboard.

  • Claude with tool use — the model calls check_availability and book_appointment; the booking engine, not the model, decides what's actually open.
  • Compliance gate — consent types, quiet hours, per-state overrides, and STOP handling are enforced in code before any message is sent, so texting rules don't depend on the AI behaving.
  • Zero dependencies — Node 22 with the built-in SQLite, HTTP, and fetch; hand-written Twilio and Anthropic clients; 46 automated tests.
  • Owner dashboard — invite-based login, hashed passwords, HttpOnly sessions.

How I Work

The software is only useful if it survives contact with a real business. That's the part I've been doing for a decade.

Start From the Workflow

Every tool above began as a process I'd run by hand — quotes, scheduling, vendor follow-up, chasing invoices. I build the version of that process that doesn't need me in the loop.

Keep the Rules Out of the Model

AI handles the conversation. Code handles the rules — who can be texted, when, what's bookable, what a quote must contain. That's why the compliance gate and the booking engine are deterministic.

Ship, Measure, Adjust

Real usage beats a spec. I put the tool in front of the business, watch what breaks, and fix the next thing. The dashboards exist so the owner (often me) can see it happening.
